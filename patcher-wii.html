Bantuan
  • Game yang dibutuhkan: disk Heroes dari Sengoku Basara 2 Heroes Double Pack versi Jepang (ID game RBSJ08), dump dari disk milikmu sendiri, dalam format RVZ.
  • Punya ISO atau WBFS? Ubah dulu ke RVZ di Dolphin. Di PC: klik kanan game → Convert File…. Di Android: tekan lama game di daftar → Convert File. Pilih Format RVZ, Compression Zstandard (bawaan), lalu Convert. File aslimu tidak diubah.
  • Butuh ruang kosong ±4,5 GB untuk ISO baru.
  • Di Chrome/Edge desktop kamu memilih lokasi simpan dulu, lalu ISO ditulis langsung ke sana. Di HP/Android, ISO langsung diunduh secara streaming (hemat memori) ke folder Download; tunggu sampai unduhan selesai.
  • HP: biarkan layar menyala dan jangan pindah aplikasi sampai selesai. Proses memakai semua inti CPU, jadi HP bisa terasa hangat.
  • Hasilnya dibuka di Dolphin (PC/Android). Mau lebih hemat ruang? Ubah ISO hasil ke RVZ di Dolphin (±3,8 GB). Wii asli: lewat USB Loader dengan cIOS (ISO hasil memakai fakesign).
  • Setiap bagian ISO dicocokkan dengan patch. Kalau dump-mu berbeda (versi lain atau sudah diubah), proses berhenti dengan pesan kesalahan, bukan menghasilkan ISO rusak.
  • Semua proses terjadi di perangkatmu. Tidak ada file yang diunggah ke mana pun.
